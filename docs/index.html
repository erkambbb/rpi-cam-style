rpi-cam-style

Make simulator frames look like they were captured by a real camera. Default profile: Raspberry Pi High Quality Camera (Sony IMX477) with a 12 mm lens.

Field of viewCrops and zooms to the lens FOV: 29.4° horizontal, 16.8° vertical in 16:9.
Color and toneSaturation, contrast, white balance, histogram match to your real frames.
Optics and sensorHaze, vignetting, softness, chromatic aberration, shot and read noise.
Labels followYOLO boxes are transformed with the same geometry. Out-of-frame boxes are dropped.

Install

pip install numpy opencv-python
git clone https://github.com/erkambbb/rpi-cam-style
cd rpi-cam-style

Quick start

Stylize a YOLO dataset (images/ and labels/ folders):

python -m camstyle datasets/my_sim_set datasets/my_sim_set_cam \
    --source-hfov 60 \
    --reference real_camera_samples/ --match-strength 0.3 --ignore-top 45

Or a plain folder of images: python -m camstyle input/ output/ --source-hfov 60.

The simulator must render wider than the camera. The 12 mm lens needs about 29.4°. Use 50–60° in the simulator and pass that value as --source-hfov.

Tuning

Take 5–10 real frames with the camera (sky, ground, horizon) and pass them as --reference. Compare output and real frames side by side. Then adjust, in this order: --match-strength, --haze, --ev, --wb, --photon-scale. Do not tune on one image.

Limits

This is an approximation. It does not model the sensor's color matrix, demosaicing or the camera ISP. Validate the output against your own frames before training on it.
